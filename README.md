**Adverse Drug Reaction (ADR) Reporting Form – Pharmacovigilance**

This project demonstrates a sample Suspected Adverse Drug Reaction (ADR) Reporting Form based on the Pharmacovigilance Programme of India (PvPI) guidelines. It includes patient information, suspected drug details, adverse reaction descriptions, concomitant medications, seriousness assessment, and causality reporting using a sample case of amoxicillin-associated adverse reactions.
